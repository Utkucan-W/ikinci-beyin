# İkinci Beyin — Vault

Bu klasör senin kalıcı hafızandır. Claude her oturumda buradan okur ve buraya yazar.

| Klasör | Ne için |
|---|---|
| `📥 000-Inbox` | Henüz yeri belli olmayan hızlı notlar. Düzenli boşalt. |
| `🏰 300-Projects` | Projeler. Her proje kendi klasöründe. Günlük raporlar burada. |
| `🧠 500-Knowledge` | Kalıcı bilgi: öğrendiklerin, referanslar, nasıl-yapılır notları. |
| `🔮 850-Companion` | **Asistanın hafızası.** Otomatik okunur/yazılır. |
| `📦 900-Archive` | Biten ve artık dokunulmayan işler. |

`🔮 850-Companion` dışındakiler senindir; istediğin gibi düzenle, yenilerini ekle.
`850-Companion` içindeki dosya adları motor tarafından bilinir — **yeniden adlandırma.**

## Sırlar

Parola, token ve API anahtarını **hiçbir nota yazma.** Bu vault'u Git'e
gönderirsen sırlar geçmişe kalıcı olarak işlenir.
